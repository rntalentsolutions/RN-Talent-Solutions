## Hosting
Upload all files and the `assets` folder to the public root of your hosting account. Keep the folder structure unchanged.

For a static site, no database or server-side code is required. The client inquiry form opens the visitor's email application with a prepared message.

## Important before launch
1. Confirm the company phone/email and legal business details.
2. Add the final physical business address if you want it displayed.
3. Connect a real form backend (Formspree, HubSpot, Zoho, etc.) if you want web-form submissions without requiring the visitor's email application.
4. Have a qualified attorney review any commercial/legal language before publishing it as a contractual promise.
5. Add a verified domain and SSL certificate through your hosting provider.
